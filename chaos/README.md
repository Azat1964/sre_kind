# Хаос-эксперименты

Здесь будут манифесты Chaos Mesh и описания сценариев сбоев.

## Ручные сбои (без Chaos Mesh)

```bash
# Убить под — Kubernetes перезапустит его
kubectl delete pod -l app=nginx

# «Убить» воркер — поды переедут на другой воркер
docker kill chaos-lab-worker

# Вернуть воркер
docker start chaos-lab-worker
```

## Что фиксировать в каждом эксперименте

- время сбоя;
- время обнаружения (кластер заметил проблему);
- время восстановления;
- что наблюдал в `kubectl get pods -o wide`.
